# Runtime provider contracts

HookProvider methods describe an interface, not verified native detours or atomic pointer cleanup for every architecture. Attach, verify, replace, detach, and cleanup need implementation-specific evidence. Resource replacement and memory interception are different operations.

See [engine support](../engines/ENGINE_SUPPORT_MATRIX.md), [the SDK limits](../development/PLUGIN_SDK.md), and [the detailed guide](../GUIA-DETALHADO.md).
