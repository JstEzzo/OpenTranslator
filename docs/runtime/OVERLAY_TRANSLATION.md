# Universal Overlay Translation Specification

O modo **OVERLAY** é o método não invasivo universal do OpenTranslator:
- Cria uma camada transparente sobre a janela do jogo.
- Renderiza caixas de texto traduzidas alinhadas às coordenadas originais.
- Ideal para jogos com engines desconhecidas, packers proprietários ou versões sensíveis a modificações binárias.
