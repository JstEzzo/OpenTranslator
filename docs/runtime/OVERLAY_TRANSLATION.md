# Overlay translation

Overlay is a strategy that needs a working capture/input source, translation path, window synchronization, and renderer. Test fullscreen modes, display scaling, OCR language data, and game compatibility. An overlay class or READY label is not proof of a working universal screen translator.

See [engine support](../engines/ENGINE_SUPPORT_MATRIX.md), [the SDK limits](../development/PLUGIN_SDK.md), and [the detailed guide](../GUIA-DETALHADO.md).
